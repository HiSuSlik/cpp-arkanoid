# Курсовая работа. ARKANOID

## Условие задачи
В верхней части поля расположены прямоугольные блоки. В нижней части горизонтально перемещается каретка. По полю движется мяч, отражаясь от стен, блоков и каретки. Если мяч проходит ниже каретки, фиксируется потеря.

Реализованы пункты задания:
1. Неразрушаемые блоки.
2. Блоки со спрятанными падающими бонусами.
3. Блоки, увеличивающие скорость мяча при столкновении.
4. Блоки с запасом прочности.
5. Бонусы изменения размера каретки, скорости мяча и прилипания мяча к каретке.
6. Одноразовое нижнее дно.
9. Бонус второго мяча, который взаимодействует с первым мячом, блоками и стенками.

## Структура проекта
- `include/Config.h` — параметры окна, поля и анимации;
- `include/GameTypes.h` — базовые структуры мяча и каретки;
- `include/Bonus.h`, `src/Bonus.cpp` — базовый класс падающего бонуса, классы-наследники и фабрика бонусов;
- `include/Block.h`, `src/Block.cpp` — базовый класс блока, классы-наследники для разных типов блоков;
- `include/Game.h`, `src/Game.cpp` — игровое окно, цикл приложения, обработка ввода, столкновений и интерфейс;
- `src/main.cpp` — точка входа;
- `CMakeLists.txt` — конфигурация сборки.

## Требования
- Windows
- Компилятор со средствами разработки C++
- CMake
- Git

## Сборка и запуск
1. Открыть терминал в папке проекта.
2. Запустить `build_windows.bat`.
3. После успешной сборки исполняемый файл будет создан в каталоге `build\Release`.
4. Запустить `ArkanoidLabSFML.exe`.

## Управление
- `A` / `D` или стрелки влево/вправо — движение каретки
- `Пробел` — запуск прилипшего мяча
- `P` — пауза
- `R` — перезапуск уровня
- `Esc` — выход
